final class ContractBinding

Binds written arguments to declared parameters and resolves references.

Binding follows the same rules PHP applies at the call site: positional arguments in order, named arguments by name, and declared defaults for the rest. A reference to a parameter that does not exist is a declaration error; a value the analysis cannot read stays unresolved and is never replaced with a default or a guess.
