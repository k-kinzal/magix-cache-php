CliGraphpackages/magix-cache-cli/src/Graph/EffectCalculator.php:28
final class EffectCalculator

Applies the composition rules of MagixCache to a statically read boundary.

The calculator works on TtlEstimate values, so "no constraint" and "not

  • statically decidable" stay separate all the way to the output. Dependency

composition uses meet. Explicit local settings replace the selected fields in the same priority order as runtime, with strategies applied last.

96%source§

Returns the estimate of a lifetime derived from the upstream expiration.

Ttl::Auto and Ttl::FromUpstream require a finite upstream expiration. A later expiration override can fulfill the requirement. A maxTtl that was declared but could not be read is a missing source, not a missing declaration, so it is never an error; otherwise a confirmed missing expiration is an error unless the boundary itself supplies metadata or resolves a lifetime at runtime, and an unknown one keeps the requirement as a runtime condition.
