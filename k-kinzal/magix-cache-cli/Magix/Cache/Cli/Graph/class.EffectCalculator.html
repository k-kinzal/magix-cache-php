public function fixed(int $declared, TtlEstimate $upstream, string $source): TtlEstimate
100%source§

Returns the estimate of a fixed lifetime bounded by its upstream.

A fixed lifetime is always capped by the upstream expiration and never fails: with no upstream constraint the declared value stands, and with an unknown upstream only the declared value remains as an upper bound.
