public function root(CacheNode $node): list<CacheNode>
100%source§

Retains the analyzed method itself, which names what the report answers.

An entry point that converts its result, such as a controller action that renders a response, declares no cache of its own. Selecting it as a row would drop the very method the command was asked about, so only --ignore removes it.
