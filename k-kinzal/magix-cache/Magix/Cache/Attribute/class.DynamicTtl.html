final class DynamicTtl

References a registered resolver that adds a per-result lifetime constraint.

The attribute carries only the reference: the resolver instance is registered with the runtime at bootstrap, and the runtime meets the resolved lifetime with the origin metadata using the fixed composition law. One boundary declares at most one resolver.
