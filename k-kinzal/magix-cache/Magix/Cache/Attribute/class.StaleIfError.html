final class StaleIfError

Serves a retained expired entry when the origin fails with a declared exception.

Only the origin call is inside the capture range, and only failures the origin declares as behavior are eligible: every declared type must be a RuntimeException subtype, and an empty list is rejected. Bugs — the LogicException family and PHP Errors — are never RuntimeException, so they can never trigger the fallback; an origin that meets an expected outage in a foreign exception hierarchy translates it into its own declared type.
