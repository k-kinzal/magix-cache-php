final class TerminalCacheStrategy
    implements CacheStrategy

Ends every strategy chain with the fixed stage bodies of the runtime.

The terminal answers each operation itself and never delegates: get is the guarded lookup with the fresh-hit judgement, fetch is the origin call inside the stale-if-error capture range, and set is the re-judged store. Only the origin call sits inside the capture range, and the capture takes only the RuntimeException family; only cache reads and writes sit inside the backend bypass range.
