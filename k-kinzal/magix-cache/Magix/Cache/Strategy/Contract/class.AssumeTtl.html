final class AssumeTtl

Declares an explicit analysis assumption for one composed strategy.

The declaration replaces exactly one analysis item — the lifetime contract of the named child strategy — when its construction or contract cannot be read statically, such as a strategy built by an external factory. It never changes what runs, never corrects a runtime value into the declared range, and never marks effects it does not mention as analyzed. Reusable behavior belongs in the contract of the strategy itself; this attribute only feeds the analysis of the composition it is declared on.
