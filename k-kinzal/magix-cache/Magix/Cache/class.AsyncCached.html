classAsyncCached

CoreApipackages/magix-cache/src/AsyncCached.php:26
final class AsyncCached<T>
    uses AsyncCombinations

An eventual value with cache metadata, never a promise-valued payload.

Composition registers continuations without waiting. toCached() and value() are the synchronous boundaries. map preserves nested Cached values; flatMap and flatten meet dependencies and remove exactly one wrapper.
