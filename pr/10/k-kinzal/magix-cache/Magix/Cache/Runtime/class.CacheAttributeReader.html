final class CacheAttributeReader

Reads one attribute kind with method-over-class precedence.

A method-level attribute replaces the class-level attribute of the same kind as a whole. Class defaults are read from the concrete class only: parent-class attributes are never inherited implicitly, while an inherited method keeps the attributes of the method it reflects to.
