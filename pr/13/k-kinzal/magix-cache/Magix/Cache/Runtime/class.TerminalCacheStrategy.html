final class TerminalCacheStrategy
    implements CacheStrategy

Executes the fixed storage and origin stage bodies without feature policy.

Lookups expose retained data, origin calls report success or declared failure, and writes recheck storage eligibility. Strategies own all fallback decisions. Only the origin call becomes an OriginFailure.
