final class ConstructorArg

An explicit contract reference to one constructor argument by name.

The reference binds to the value passed to the constructor of the strategy that declares the contract, not to a normalized property the constructor may derive from it. The analyzer resolves the reference against the construction code; the name alone never makes it guess a meaning.
