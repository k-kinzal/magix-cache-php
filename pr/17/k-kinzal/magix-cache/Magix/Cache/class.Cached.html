classCached

CoreApipackages/magix-cache/src/Cached.php:32
final class Cached<T>

Carries an evaluated value together with its cache constraints.

The composition API preserves the constraints of every dependency it is given: map and unzip keep this value's metadata; flatMap, flatten, zip, sequence, traverse and combineN meet the metadata of all inputs. Extracting a value with value() detaches it from its constraints, so a dependency obtained inside map must be chained with flatMap or combineN instead.
