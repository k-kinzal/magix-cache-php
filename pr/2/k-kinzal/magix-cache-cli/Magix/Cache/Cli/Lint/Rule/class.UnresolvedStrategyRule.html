final class UnresolvedStrategyRule
    implements LintRule

Reports declared strategy compositions that cannot work as written.

A #[UseStrategy] whose class has no create(), whose arguments cannot be bound to create(), or whose contracts reference parameters that do not exist fails when the boundary is resolved or leaves the analysis with a declaration error; both are findings, not silent unknowns.
