final class CacheMetadata

Immutable cache metadata: meet dependencies, explicitly replace local fields.

Dependency bubbling uses meet: it selects the earliest finite expiration, combines cacheability with AND, chooses the stricter visibility, and unions tags and diagnostic reasons. top() is its identity, and every composition is as strict as or stricter than each input. Explicit boundary overrides use the with* methods and may relax a field.
