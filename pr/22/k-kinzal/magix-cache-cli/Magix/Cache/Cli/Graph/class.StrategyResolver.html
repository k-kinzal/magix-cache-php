final class StrategyResolver

Derives the composed contract of a declared strategy without running it.

The resolver binds the #[UseStrategy] arguments to the same create() the runtime calls, follows the composed constructions in order, binds each child contract's explicit references to the constructor values it was built with, and selects overrides in fetch return order (outermost wins). A composition never re-declares child contracts; only an explicit assumption replaces the one analysis item it names. What stays unknown stays unknown — it is never converted into a default or into "no

  • constraint".
