interface BackendErrorClassifier

Classifies storage failures for the #[BypassCacheErrors] behavior.

The runtime consults a classifier only around cache reads and writes, and only for the RuntimeException family the Cache port declares its failures in; origin failures, definition errors, and bugs never reach it. A classified read failure becomes a miss and a classified write failure becomes a skipped write, while everything else propagates unchanged.
