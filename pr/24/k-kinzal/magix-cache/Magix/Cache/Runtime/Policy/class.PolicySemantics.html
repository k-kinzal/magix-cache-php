final class PolicySemantics

Applies explicit policy fields without recomposing dependency metadata.

Auto inherits expiration. FromUpstream caps the inherited expiration. A fixed TTL replaces it. Unspecified tags and visibility are preserved. Finite-expiration validation runs after dynamic and strategy overrides.
