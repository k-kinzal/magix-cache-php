final class TtlAssumption

Holds one explicit analysis assumption declared on a composition.

The assumption stands in for the lifetime contract of exactly one composed strategy when that contract cannot be read statically. It is an input to this analysis only: it changes nothing at runtime and marks no other effect as analyzed.
