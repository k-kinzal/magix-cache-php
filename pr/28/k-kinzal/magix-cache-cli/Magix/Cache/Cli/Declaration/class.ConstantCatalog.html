final class ConstantCatalog

Holds the constant expressions a declaration may reference.

PHP restricts attribute arguments to constant expressions, so every value a cache policy declares is statically decidable. What a single file cannot see is the expression behind a constant declared elsewhere; this catalog supplies it, so an unreadable declaration is a missing source, never a missing rule.
