public function definition(string $class, string $method): CacheDefinition
100%source§

Returns the resolved declaration the runtime would derive the key from.

The declaration is resolved exactly like at runtime, on an instance created without its constructor, so the key carries the same version and declaration fingerprint the runtime stores entries under. A boundary that declares no #[Cache] is the caller's mistake and is checked before this method runs; here it surfaces as the same LogicException the runtime raises.
