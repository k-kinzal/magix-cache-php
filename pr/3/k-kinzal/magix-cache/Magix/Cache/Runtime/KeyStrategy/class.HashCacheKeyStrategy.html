Returns an opaque SHA-256 cache key.

PHP refuses to serialize a Closure or an internal object such as PDO, and reports that refusal as a bare \Exception. That refusal is what this catch is for. An Error raised by the caller's own __serialize() is a bug in that method, and relabelling it as an unusable key would hide it.
