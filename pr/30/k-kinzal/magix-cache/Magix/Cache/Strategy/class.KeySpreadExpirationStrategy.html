final class KeySpreadExpirationStrategy
    implements CacheStrategy

Spreads expirations across keys to avoid synchronized expiry.

On every successful fetch return the strategy overrides the lifetime of the produced metadata, chosen deterministically from the key so that entries written in the same instant expire spread over the declared range instead of together. Knowing the range does not mean the runtime values distribute evenly; the contract only bounds them.
