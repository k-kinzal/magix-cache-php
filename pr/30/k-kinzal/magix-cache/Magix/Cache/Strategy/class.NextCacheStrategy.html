final class NextCacheStrategy

The bound remainder of a strategy chain, invoked as $next.

A strategy receives its continuation as this type: each operation runs the rest of the chain without asking the caller how the chain continues. The end of a chain answers no operation, so the last strategy — the terminal the runtime appends — must answer every operation itself.
