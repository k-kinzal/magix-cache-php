interface CacheStrategy

Middleware over cache reads, argument-free origin inquiries and cache writes.

Each next closure performs just the corresponding operation. Middleware may change its arguments or response, catch its declared failures, or not call it. A composition implements this same interface. It neither owns the actual operations nor requires them to implement CacheStrategy.

One invocation uses fresh instances, shared across get/fetch/set. Dependencies such as clocks belong to constructors; operation arguments contain only data.

Wraps an origin inquiry and may transform its eventual Cached response.

The key identifies this cache boundary for key-dependent metadata rules. It is not an origin input: next takes no arguments. Use then for post-processing and rejection callbacks for delayed failures. Every resolved response must preserve the boundary's value type and honor declared metadata effects.
