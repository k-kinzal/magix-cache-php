final class LiteralReader

Reads the constant expressions MagixCache attributes are written with.

Source lookup and the admitted declaration value domain belong to this reader. Deriver evaluates operations within that domain. Unsupported or incomplete derivations remain unresolved rather than becoming policy facts.
