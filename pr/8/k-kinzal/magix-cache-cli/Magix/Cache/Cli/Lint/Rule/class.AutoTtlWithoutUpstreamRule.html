final class AutoTtlWithoutUpstreamRule
    implements LintRule

Reports derived TTLs whose finite upstream expiration never exists.

An upstream that is confirmed unconstrained is an error, because applying the policy throws at runtime. An upstream the analyzer cannot decide is only a conditional requirement and is reported as a notice.
