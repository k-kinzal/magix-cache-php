final class OriginConstraints

Applies the fixed success-stage constraint order at one base time.

Parameter and dynamic-TTL constraints are met before the policy, all evaluated at the same base time taken right after the origin succeeded. Every step goes through the metadata meet, so no step can relax what a dependency already imposed.
