7/**
8 * Base class for strategy compositions built by a typed static create() definition.
9 *
10 * A subclass declares one public static create() that takes typed arguments,
11 * describes its child strategies, and connects their definitions with compose().
12 * The returned definition composes again. The runtime constructs a fresh
13 * composition for each execution; no executable instance is memoized.
14 *
15 * The composition never re-declares the contracts of its children. The
16 * analyzer binds the create() arguments to the same construction code and
17 * derives the composed contract from the child contracts, so create() only
18 * has to build what actually runs. A child whose construction is outside
19 * the analyzable sources can be covered with an explicit
20 * Contract\AssumeTtl declaration on create().
21 */
22abstract class CompositeCacheStrategy
23{
24    /**
25     * Connects strategies into one, in delegation order.
26     *
27     * The first strategy wraps everything after it: its pre-processing runs
28     * first, its post-processing last, and its failure capture surrounds the
29     * delegates. The result composes again.
30     */
31    final protected static function compose(StrategyDefinition $first, StrategyDefinition ...$rest): StrategyDefinition
32    {
33        return StrategyDefinition::compose($first, ...$rest);
34    }
35}
